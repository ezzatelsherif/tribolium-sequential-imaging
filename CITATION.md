Theophilus Frimpong supplied the spatial/temporal measurements and developed
the original profile viewers. The processing conventions in `seqimaging/`
follow these sources:

- [gap-gene-visualization](https://github.com/Theophilus-Dwamena/gap-gene-visualization/tree/e662f1b4af45df5d1ba3d62915c21bcf57d8a5b3): `app.py`, `stage_utils.py`, and `temporal_utils.py`.
- [gap-gene-visualization-int](https://github.com/Theophilus-Dwamena/gap-gene-visualization-int/tree/7121c65d65b4d8979282d9ebb1edb97a5af5b304): intronic/exonic profile viewer and the stage 4.2 EMB_3 source used in Fig. S3.

These upstream repositories are provenance references, not runtime dependencies.
Only the manuscript's selected datasets are included in this release.
The original intron/exon package is retained from this repository's commit
`4d3951c80bdfe4ed3ad6f824643826458e42fd25`; its methodological references and
original release documentation remain with that package.
