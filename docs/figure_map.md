# Manuscript figures and reproduction commands

Commands below are run from the repository root. The output directory defaults
to `outputs/`. The original microscopy panels, staging diagrams, and assembled
Illustrator layouts are not generated by these numerical workflows.

| Manuscript component | Source | Command | Output |
|---|---|---|---|
| Fig. 2C numerical profile example | Exonic stage 4.1, EMB_1 | `python reproduce.py profiles` | `profiles/Figure_2C_profiles.*` |
| Fig. 3B simulation | Mapped Kr target geometry, hypothetical pulse | `python reproduce.py model --stage manuscript-figures` | `model/figures/_parts/panel_B.pdf`, `model/figures/illustrative_profiles.csv` |
| Fig. 3C target maps and fitted profiles | Target geometry, KR/MLPT/SVB workbooks, saved joint fits | Same model command | `model/figures/_parts/map_*.pdf`, `model/figures/_parts/data_*.pdf` |
| Fig. 3E half-height offsets | Paired temporal measurements and bootstrap results | Same model command | `model/figures/_parts/offsets.pdf` |
| Fig. 3F numerical spatial overlays | Intron/exon stage 4.2, EMB_1 | `python reproduce.py profiles` | `profiles/Figure_3F_spatial_overlays.*` |
| Fig. 4B | Intron/exon stages 3.3, 4.2, 4.3, EMB_1 | `python reproduce.py profiles` | `profiles/Figure_4B.*` |
| Fig. 5B temporal profiles | Seven temporal workbooks; each gene and its co-measured eve | `python reproduce.py profiles` | `profiles/Figure_5_temporal_profiles.*` |
| Fig. 6A-D | Exonic EMB_1 at four stages; temporal workbook reference | `python reproduce.py profiles` | `profiles/Figure_6A.*` through `Figure_6D.*` |
| Fig. S1A-D | Exonic EMB_2 at the same four stages | `python reproduce.py profiles` | `profiles/Figure_S1A.*` through `Figure_S1D.*` |
| Fig. S2A-D | Exonic EMB_3 at the same four stages | `python reproduce.py profiles` | `profiles/Figure_S2A.*` through `Figure_S2D.*` |
| Fig. S3 | All 1,944 mapped-target simulations | `python reproduce.py model --stage manuscript-figures` | `model/figures/Figure_S3.*` |
| Fig. S4 | Saved constrained fits and residuals | Same model command | `model/figures/Figure_S4.*` |
| Fig. S5 | Intron/exon EMB_1 and EMB_3 at stages 4.2 and 4.3 | `python reproduce.py profiles` | `profiles/Figure_S5.*` |
| Movie S1 | The same illustrative Kr simulation as Fig. 3B | `python reproduce.py model --stage movie` | `model/figures/Movie_S1.mp4` |

`.*` denotes PDF, SVG, and PNG unless a specific extension is listed. The
Fig. 3 components are individual PDFs. Full source-file assignments are in
`data/manifest.csv` and `config/figures.json`.

The temporal reference in Fig. 6, S1, and S2 is reused; those supplements add
spatial biological replicates, not new temporal cohorts. Current Fig. 6B/C
contains two gap-gene curves per panel, whereas S1B/C and S2B/C also contain
eve. The configuration follows the supplied figures. See the version
qualifications in [data_notes.md](data_notes.md).

## Exported numerical tables

| Table in `outputs/profiles/` | Contents |
|---|---|
| `temporal_measurements.csv` | All source slots, original and corrected ROI values, cached display value, completeness, correction identifiers |
| `temporal_stage_summary.csv` | Per-cohort/channel stage statistics for raw correction and cached display values |
| `comparison_temporal_profiles.csv` | Exact stage summaries used in Fig. 6/S1/S2, including pooled eve |
| `spatial_profiles.csv` | Source-file identity, stage, embryo, gene, normalized AP position and smoothed intensity |
| `settings.json` | The configuration used to generate the run |

The archived model CSV/JSON results are in `analysis/intron_exon/`; rerun
results have the same relative names under `outputs/model/`. Analysis figures
can also be regenerated with `python reproduce.py model --stage figures`.
