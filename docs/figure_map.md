# Manuscript figures and reproduction commands

This map uses the final revised manuscript's figure numbering. Analysis commit
`19370cf` predates the supplemental renumbering, so generated output filenames
retain their original labels: output S1/S2/S3/S4/S5 corresponds to final
S4/S5/S1/S2/S3, respectively.

Commands below are run from the repository root. The output directory defaults
to `outputs/`. The original microscopy panels, staging diagrams, and assembled
Illustrator layouts are not generated by these numerical workflows.

Fig. 3 components are individual PDFs. Full source-file assignments are in
`data/manifest.csv` and `config/figures.json`.

spatial biological replicates, not new temporal cohorts. Current Fig. 6B/C
contains two gap-gene curves per panel, whereas S4B/C and S5B/C also contain
eve. The configuration follows the supplied figures. See the version
qualifications in [data_notes.md](data_notes.md).

## Exported numerical tables

| Table in `outputs/profiles/` | Contents |
|---|---|
| `temporal_measurements.csv` | All source slots, original and corrected ROI values, cached display value, completeness, correction identifiers |
| `temporal_stage_summary.csv` | Per-cohort/channel stage statistics for raw correction and cached display values |
| `comparison_temporal_profiles.csv` | Exact stage summaries used in Fig. 6/S4/S5, including pooled eve |
| `spatial_profiles.csv` | Source-file identity, stage, embryo, gene, normalized AP position and smoothed intensity |
| `settings.json` | The configuration used to generate the run |

The archived model CSV/JSON results are in `analysis/intron_exon/`; rerun
results have the same relative names under `outputs/model/`. Analysis figures
can also be regenerated with `python reproduce.py model --stage figures`.

## Second-revision peak-order outputs

The peak-order package reconstructs the numerical content of Fig. 7 and S6
and the complete S1 Data inventory from the existing measurements. It includes
curated episode windows and domain-family identities as explicit scientific
inputs, and does not infer these identities afresh from microscopy. No spatial
averaging or sequence-distance metric is used. The generated companion uses
the Fig. 7 version 08 palette; the submitted FigS6.pdf still had the earlier
palette at the audit date. The Fig. 7 export reproduces the audited layout,
which requires reflow before journal submission because of its height.

The historical reference CSVs are checks, not substituted results. See
[the package README](../analysis/peak_order/README.md) for output names,
uncertainty assumptions, source-input hashes, and the independently rerun
late-background-correction sensitivity.
