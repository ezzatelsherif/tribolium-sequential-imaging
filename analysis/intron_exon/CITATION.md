# Citation

This package is **S1 Code: Intron–exon signal analysis for sequential imaging**,
accompanying the revised sequential-imaging study supplied by Ezzat El-Sherif.

When reusing these analyses, cite the associated manuscript and identify the
exact version of the code. If deposited in a repository, use its immutable
commit URL or an archived release identifier. A manuscript DOI, software DOI,
repository URL, and definitive software-author list have not been assigned in
this package, and none is inferred here.

The accompanying manuscript and S1 Text describe the methods and their
scientific and software references. Package versions used for the recorded
analysis are in `environment.json`. The five added references are also supplied
as importable metadata in `references.ris`. No software license has been selected.
